# Protótipos do app

Desenhos de tela feitos pelo agente `designer` (`.claude/agents/designer.md`), em HTML estático, **só como referência** para o desenvolvedor. O app de verdade é `index.html` + `styles.css` + `js/`.

Para abrir no PC (a partir da pasta do projeto, para o protótipo achar o `styles.css`):

```
python -m http.server 8765
```

Depois abra `http://localhost:8765/prototipos/<n>-<assunto>/` no Chrome.

Regras: o repositório é público, então só dados fictícios; nunca final de cartão, saldo, nome, CPF, cupom ou print real.
